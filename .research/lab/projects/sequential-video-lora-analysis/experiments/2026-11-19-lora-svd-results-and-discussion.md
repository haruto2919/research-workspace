## 1. 何をしたか

### 1.1 問い

MTG で挙がった次の問いに，重みだけから答える．

1. LoRA は，事前学習の重み W₀ に比べてどれくらい動いたか．教授の予想は「ほとんど動いていない」．
2. どの層，q と v のどちら，どのヘッドが動いたか．
3. 学習の進みにつれて，大きさと向きはどう変わるか．
4. シャッフルして読んだ LoRA と，動画を先頭から順に読んだ LoRA で違いはあるか．

### 1.2 解析した学習

すべて同じ ViT-B/16 と MoCo で学習している．

- **共通の設定**：
  - LoRA：q と v，rank 8，alpha 8（倍率 1）
  - MoCo：K 65,536
  - 学習：学習率 3e-4（一定），AdamW，seed 0，FP32

- **Full FT**：同じ設定で，LoRA を使わずに重み全体を学習したもの．
- **ΔW**：
  - LoRA では B·A．
  - Full FT では，学習後の重みから W₀ を引いたもの．

### 1.3 方法

- **対象**：LoRA を付けた 24 個の行列（12 層 × q・v，各 768×768）．それぞれ ΔW を特異値分解した．
- **2 つの見方**：
  - **差分 ΔW**：ΔW そのものを分解した．
  - **そのまま W₀+ΔW**：学習後の重みを分解し，W₀ の分解と比べた．
- **指標**：

  | 指標 | 式 | 見るもの |
  |---|---|---|
  | 最大特異値の比 | σ₁(ΔW) ÷ σ₁(W₀) | MTG で決めた「事前学習の重みの特異値との比較」 |
  | ノルムの比 | ‖ΔW‖_F ÷ ‖W₀‖_F | MTG で決めた「初期値からの距離」．B の初期値は 0 なので，学習前の ΔW は 0 |
  | 有効ランク | exp(−Σ pᵢ log pᵢ)，pᵢ = σᵢ² ÷ Σσⱼ²（上位 8 個） | 実質いくつの向きを使ったか（1〜8） |
  | 上位 8 成分の割合 | Σ_{i≤8} σᵢ² ÷ ‖ΔW‖²_F | Full FT の ΔW が，上位 8 個の向きにどれだけ集まるか |
  | σ₁ の変化 | σ₁(W₀+ΔW) ÷ σ₁(W₀) − 1 | 学習後の重みで，最も強い成分がどれだけ変わったか |
  | 部分空間のずれ | 1 − φ，φ = ‖U₀ᵀU′‖²_F ÷ 16 | W₀ の上位 16 本の出力側の向きが張る空間から，学習後にどれだけ外へ出たか |
  | 新しい向きの本数 | W₀+ΔW の上位 16 本のうち，W₀ の全 768 本との最大 \|cos\| がしきい値より小さいもの | 学習で新しく加わった向き（文献の intruder dimension）．しきい値は仮で，0.3・0.5・0.7 の 3 通りを示す |
  | ヘッドへの集中 | 12 ヘッドのうち最大の ‖ΔW のヘッド部分‖² ÷ ‖ΔW‖²_F | 均等なら 1/12 = 8.3% |
  | run どうしの重なり | φ(8, 8) = ‖AᵀB‖²_F ÷ 8（A・B は 2 つの ΔW の上位 8 本の特異ベクトル） | 2 つの LoRA が同じ向きを学んだか．無関係なら約 8/768 = 0.010 |

- **集計**：断りがなければ，24 個の行列の**中央値**と［最小〜最大］を示す．

## 3. わかること

### 3.1 LoRA は「ほとんど動いていない」わけではない

- LoRA の最大特異値は，W₀ の最大特異値に比べて小さくない（2.1）．
  - シャッフルの短い学習でも 16〜29%（中央値）．
  - 順に読む 6,255 step の学習では 68%（中央値）．
  - 層 2・3 の q では，W₀ を上回った（最大 140%）．
- MTG で例に挙がった「0.1% 程度なら学習していないのと同じ」と比べると，2〜3 桁大きい．
- 一方，行列全体の大きさ（フロベニウスノルム）で見ると，W₀ の 2.5〜13%．

### 3.2 LoRA の変化は，ごく少数の向きに集まっている

- **LoRA**：有効ランクは，rank 8 のうち 1.8〜3.5（2.1）．実質 2〜3 個の向きしか使っていない．そのため，最大特異値の比が大きい一方で，ノルムの比は小さい．
- **Full FT**：ΔW は多くの向きに広がっている．上位 8 個の向きで説明できるのは，全体の 10〜14% だけ．
- **ImageNet の同じ 1,000 step での比較**：
  - Full FT のほうがノルムは大きい（10.6% と 4.2%）．
  - LoRA のほうが最大特異値は大きい（28.5% と 11.0%）．

### 3.3 大きさの差は，主に学習の長さで決まっている

- 同じ step 1,000 で比べると，シャッフルの ImageNet と順に読む 3 つの学習は，ほぼ同じ大きさだった（2.2）．
  - ノルムの比：4.19〜4.32%
  - σ₁ の比：27〜29%
- 459 step の 2 つ（単一フレーム，4 フレーム clip）も，互いにほぼ同じ（2.5%，16.5%）．
- 順に読む学習は，6,255 step まで大きくなり続けた（2.6）．
  - ノルムの比は 4.3% → 12.1%．
  - 1,000 step ごとの変化は，最初の 2.1 から 1.5 前後に下がった後，ほぼ一定．止まる様子はない．

### 3.4 学習後の重みでは，W₀ の主な向きはほぼ保たれる．ただし長い学習では新しい向きが出てくる

- **σ₁ の変化**：中央値で −0.0〜+2.2% と小さい（2.4）．LoRA の ΔW 自体は W₀ の σ₁ の 16〜68% の大きさがあるので，ΔW の主な向きは W₀ の最も強い向きと重なっていない，と読める（4.2 で考察）．
- **459〜1,000 step の学習**：W₀ の上位 16 本が張る空間からのずれは 0.1〜2%．新しい向き（しきい値 0.5）は 0 本．
- **順に読む 6,255 step の学習**：
  - ずれは 7〜8%．
  - 新しい向きが 12〜21 本（384 本中），12〜15 個の行列に出た．step 1,000 では 0 本で，step 2,000 以降に増えた．
  - 新しい向きの多くは，学習後の重みの成分 1〜3 番という，強い成分に出ている．
  - σ₁ が 1.5 倍以上になったのは，層 2・3 の q．

### 3.5 層：入力に近い層が大きく，層 12 の v が最も小さい

- 9 run すべてで，ノルムの比が最も小さい行列は**層 12 の v**だった（2.3）．
- 最も大きい行列は，層 1・2 にあった．
  - シャッフルの LoRA：層 2 の v，または層 2 の q．
  - Full FT：層 1 の v．
  - 順に読む学習：層 2 の q．
- **順に読む学習では，層 1〜4 の q が特に大きい**（17.9〜22.8%，ほかの部分は 8〜14%）．シャッフルの短い学習では，q と v に大きな差はない．

### 3.6 ヘッド：複数フレームを入れた学習だけ，層 1 q のヘッド 5 に集中する

- **LoRA 全般**：最大ヘッドの割合は，中央値で 13.5〜18.3%．均等（8.3%）より偏っている．Full FT はほぼ均等（9.0〜9.2%）（2.5）．
- **層 1 q・ヘッド 5 への集中**：4 フレーム clip と 8 フレーム clip で学習した run だけに出た．
  - 該当する run：4 フレーム clip の LoRA と Full FT，順に読む 3 つ．
  - 順に読む 3 つでは，層 1 q の ΔW の 58〜64% がこのヘッドに集まっている．
  - Full FT でもこのヘッドが最大（23%）．
  - 画像（ImageNet）と単一フレームの run では，最も集中した行列は別の場所だった（層 1〜3 の別のヘッド）．

### 3.7 向き：LoRA と Full FT は別の向きを学び，LoRA どうしはデータが近いほど同じ向きを学ぶ

出力側 U で比べた（2.7）．

- **同じデータの LoRA と Full FT**：0.08〜0.12 と低い．無関係なときの約 0.010 よりは高い．
- **LoRA どうし**：データと読み方が近いほど高い．
  - 順に読むどうし：0.52〜0.66
  - 順に読む × 4 フレーム clip：0.25〜0.28
  - 順に読む × 単一フレーム：0.19〜0.21
  - 順に読む × ImageNet：0.14〜0.16
  - 単一フレーム × 4 フレーム clip：0.39
- **順に読む 3 つの中**：stride だけ違う組（stride 16 と 8）が最も高い（0.664）．フレーム数が違う組は低い（0.52〜0.55）．同じ step 1,000 でも同じ順だった（0.518 と 0.385〜0.406）．

### 3.8 stride やフレーム数を変えても，大きさはほとんど変わらない

- 順に読む 3 つの学習は，step 6,255 で，どの指標もほぼ同じ値になった（2.1，2.4，2.6）．
  - ノルムの比：12.0〜12.7%
  - σ₁ の比：68%
  - ずれ：7〜8%
- 違いが出たのは，向き（3.7）のほう．

## 4. 考察

### 4.1 「LoRA は効いていない」は，大きさの面では当てはまらない

- 教授の予想（ほとんど動いていない）は，最大特異値で見る限り当てはまらなかった（3.1）．LoRA は，W₀ の最も強い成分に匹敵する大きさの成分を，2〜3 個の向きに足している．
- ただし，「大きく動いた」ことは「動的な情報を持つ」ことを意味しない．
  - [並び順への反応の評価](2026-11-11-temporal-order-sensitivity-evaluation-g2-gpu-evidence.md)では，順に読む学習の LoRA は，並び順の変化にむしろ鈍くなっていた．
  - 今回の結果と合わせると，「LoRA は大きく動いたが，その変化が時間の情報を表すという証拠はない」が現状になる．
- MTG の方針（現状を示してから提案する）にとっては，この組み合わせ自体がベースラインになる．

### 4.2 LoRA は，W₀ が弱い向きを強めている可能性がある

- LoRA の σ₁ は W₀ の σ₁ の 16〜68% あるのに，学習後の重みの σ₁ はほとんど変わらない（3.4）．
  - もし ΔW の主な向きが W₀ の最も強い向きと揃っていれば，σ₁ は最大でその分だけ増えるはず．
  - そうなっていないので，ΔW は W₀ の上位の向きとは別の向きに足されていると考えられる．
- これは，LoRA 原論文の「ΔW は W で強調されていない向きを増幅する」という観察と同じ方向．
- ただし今回は間接的な推論で，ΔW の向きを W₀ の特異ベクトルに射影して直接確かめてはいない．
- 例外は，順に読む長い学習の層 2・3 の q．ここでは ΔW が W₀ を上回り，新しい強い向きが学習後の重みの上位に入ってきている（3.4）．学習が長くなると，W₀ の主な構造そのものを変え始める，と読める．

### 4.3 「シャッフル」と「順に読む」の違いは，まだ切り分けられていない

- 大きさは，同じ step 数ならほぼ同じだった（3.3）．順に読む学習の値が大きいのは，主に 6 倍長く学習したためと考えられる．
- 一方，向き（3.7）では，順に読むどうしが 0.52〜0.66，順に読む × シャッフルの 4 フレーム clip が 0.25〜0.28 と，差がある．ただし，この差は次の 3 つと重なっている．
  - 学習の長さ（459 step と 6,255 step）．
  - 読み方（シャッフルと順）．
  - 同じ初期値から始まっていること．
- 同じ step 1,000 の比較（順に読む × ImageNet 0.15〜0.19）では，データも違う．
- MTG の問い「シャッフルと順に読む学習の違い」に答えるには，条件を揃えた比較が要る（5 章）．

### 4.4 重なりが「高い」かどうかは，seed を変えた比較がないと判断できない

- 全 run が seed 0 なので，LoRA の A は同じ初期値から始まっている．
  - 入力側 V の重なりが LoRA どうしで高い（0.31〜0.79）のは，主にこのためと考えられる．
  - 出力側 U も無関係とは言えない．B の初期値は 0 だが，B の更新は A を通して計算されるので，A の初期値が同じだと B の向きも似やすい可能性がある．
- 「順に読むどうしの 0.66 は高い」と言うには，同じ条件で seed だけ変えた学習どうしの重なりを基準にする必要がある．
- 今は同じ条件の繰り返しもないので，3.8 のような数 % の差が意味のある差かも判断できない．

### 4.5 層 1 q・ヘッド 5 は，複数フレームの入力に固有の変化の候補

- 層 1 q・ヘッド 5 への集中は，複数フレームを token 結合して入れた run だけに，LoRA でも Full FT でも出た（3.6）．
- 入力が 1 枚のとき（ImageNet，単一フレーム）には出ないので，複数フレームを入れたことに関係する変化の候補になる．
- ただし，それが「フレームの間の関係（時間）」を扱う変化なのかはわからない．token の数が 4〜8 倍になったことへの適応である可能性もある．
- このヘッドの attention が，どのフレームのどの token を見ているかを確かめる価値がある．

### 4.6 学習はまだ収束していない

- 順に読む学習では，次の 4 つが step 6,255 まで変わり続けた（2.6）．
  - ノルムが増え続けた．
  - 1,000 step ごとの変化がほぼ一定だった．
  - 有効ランクが増え続けた（約 2 → 3.1〜3.5）．
  - 新しい向きが増え続けた．
- loss が後半で横ばいに近づいていた（[stride 16 の記録](2026-11-04-sequential-loader-clip-moco-lora-g2-gpu-evidence.md)）のと比べると，重みは loss ほどには落ち着いていない．
- step 1,000 の向きと最後の向きの重なりは 0.56 で，向きは学習の途中でも入れ替わっている．
- 459 step で止めたシャッフルの学習も，同じように途中の状態と考えるのが自然．

## 5. 次に確かめること（候補）

2. **条件を揃えたシャッフルと順に読むの比較**：どちらかの方法で，学習の長さを揃える（4.3）．

## 6. 主張しないこと

- LoRA が静的な情報と動的な情報のどちらを持つか．重みの解析だけからは判断できない．
- シャッフルと順に読む学習のどちらが良いか．学習の長さと初期値が揃っていない．
- stride やフレーム数の違いによる差の有無．繰り返しの学習がないので，ばらつきが分からない．
- 「新しい向き」の本数の大小．しきい値は仮の値．
- run どうしの重なりが高い理由．
